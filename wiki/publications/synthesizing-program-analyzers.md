**Authors:** A Nazari, **S Sabouri**, WB Zhu, R Jia, S Chattopadhyay, M Raghothaman
**Venue:** IEEE Visual Languages and Human-Centric Computing (VL/HCC), 2026

## Summary
Merlin, a system bridging LLMs with **CodeQL** so programmers can ask free-form questions about
large codebases. Uses RAG-based iterative query generation, with a self-test technique built on
assistive queries that expose flawed candidate queries. In a within-subject user study it
**increased task accuracy 3.8×** on average while **cutting completion time 31%**.
