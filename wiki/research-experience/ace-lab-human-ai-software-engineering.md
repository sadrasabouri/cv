How developers trust and interact with LLM-generated code, across four studies:

1. **Trust** — surveyed 29 and observed 10 developers on how they define, evaluate, and evolve
   trust in AI-generated code → [[../publications/trust-dynamics-ai-assisted-development]]
2. **Cognitive bias** — observational study of 36 developers producing a taxonomy of 15 bias
   categories covering 90 biases → [[../publications/cognitive-biases-llm-programming]]
3. **Project-level agents** — 16 developers using Cursor-like tools, identifying integration
   challenges and opportunities → [[../publications/ai-assisted-codebase-generation]]
4. **Interactive code querying** — an educational prototype letting programmers query source
   code, evaluated with 20 software engineers →
   [[../publications/synthesizing-program-analyzers]]

Partially funded by the **Amazon AGI Center**.
