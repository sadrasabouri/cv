**Role:** Creator / co-developer
**Org:** [[../industry-experience/open-science-laboratory]]

Does the "smart" placement of typed special characters and letters to form a visual shape
spread over multiple lines of text.

**Adoption:** 2.5k+ GitHub stars, 141 forks, 13M+ downloads. Added to **conda-forge**. Cited in
scientific papers on LLM security research.

**Funding:** [[../honors-and-awards/psf-grant-art]] — PSF grant for multi-line and custom font features (May 2024).
