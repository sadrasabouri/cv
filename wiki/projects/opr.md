## Summary
OPR designs, validates, and optimizes primers for PCR, qPCR, and sequencing, consolidating
primer design tooling in one library.

Its audience is biologists and bioinformaticians who would rather not do any of that by hand.
The library provides abstracted Python objects that simplify otherwise complex primer design
workflows, so the work is expressed as operations on primer objects rather than as manual
sequence bookkeeping.

OPR is developed under the OpenSciLab GitHub organisation and distributed as a Python package on
PyPI.
